# Drittanbieter und Quellen

Der PoE2 Ingame Guide nutzt Daten und Inhalte aus den folgenden Quellen. Die Rechte daran liegen bei den jeweiligen Inhabern. Der Hinweis „Alle Rechte vorbehalten“ im [README](README.md) gilt nur für den eigenen Code und die eigenen Texte der Buildschmiede.

## Grinding Gear Games

Spielbegriffe, Spieldaten sowie die Grafiken für Gegenstände, Gemmen, Passivbaum und Währungen (`app/poe2_build_art.zip`, `app/poe2_currency_art.zip`) stammen aus Path of Exile 2. Sie gehören Grinding Gear Games und werden in diesem kostenlosen Fanprojekt gemäß deren Nutzungsbedingungen verwendet. Dieses Projekt steht in keiner Verbindung zu Grinding Gear Games. Path of Exile ist eine Marke von Grinding Gear Games.

## Datenquellen

| Quelle | Verwendung | Lizenz |
| --- | --- | --- |
| [Exiled Exchange 2](https://github.com/Kvan7/Exiled-Exchange-2) | Handelstexte für den deutsch-englischen Abgleich, ein Währungsicon | MIT, siehe unten |
| [PathOfExile_Translated](https://github.com/gw1108/PathOfExile_Translated/tree/0b5e587d69b433cfe277f5689876951fd1beff47/dist/poe2) | Sprachdaten, extrahiert über RePoE (Stand 4.5.4.3) | MIT, siehe unten |
| [RePoE](https://github.com/repoe-fork/repoe) | Werkzeug, mit dem die Sprachdaten aus dem Spielclient extrahiert wurden. Die Daten selbst gehören Grinding Gear Games. | siehe Repository |
| [PoE2DB](https://poe2db.tw/) | Deutsche und englische Spieltexte zum Abgleich, Belegquelle der Mechanik-Links | öffentlich abrufbare Daten, Quellenangabe |
| [PoE2Wiki](https://www.poe2wiki.net/) | Belegquelle der Mechanik-Links | Verlinkung |
| [Path of Exile Trade](https://www.pathofexile.com/trade2) | Handelsligen und Handelsdefinitionen | offizielle Schnittstelle |
